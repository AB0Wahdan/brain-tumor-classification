# 🧠 Brain Tumor Classification

> CNN-based classification of brain MRI scans

![Python](https://img.shields.io/badge/Python-1f6feb?style=flat-square) ![TensorFlow](https://img.shields.io/badge/TensorFlow-1f6feb?style=flat-square) ![Keras](https://img.shields.io/badge/Keras-1f6feb?style=flat-square)

## 📌 Overview
A deep learning model that classifies brain MRI images to detect tumors, with a full preprocessing and data-augmentation pipeline.

## ✨ Features
- Image preprocessing and normalization
- Data augmentation to reduce overfitting
- Custom CNN architecture
- Evaluation with accuracy, confusion matrix and classification report

## 🛠️ Tech Stack
Python, TensorFlow, Keras

## 🚀 Getting Started
```bash
pip install -r requirements.txt
# place the dataset in ./data
jupyter notebook
```
